Как работают данные на YOUNOVAL

Последнее обновление: 19 ноября 2026 года.

Коротко: регистрация не требуется. Ответы, введённые показатели, заметки и результаты инструментов обрабатываются в браузере посетителя и сохраняются локально на его устройстве. Для статистики использования сайт отправляет только фиксированные события и идентификаторы инструментов; сетевые запросы при этом могут сопровождаться техническими данными, например IP-адресом.

1. Ответы и результаты инструментов

Инструменты YOUNOVAL выполняют расчёты в браузере. Ответы, финансовые значения, заметки и полученные результаты не отправляются в базу данных приложения и не доступны создателю проекта. Последний результат каждого инструмента и выбранный язык могут сохраняться в локальном хранилище браузера (localStorage), чтобы посетитель мог вернуться к ним на том же устройстве и в том же браузере.

Сохранённые результаты можно удалить кнопкой «Очистить результаты» на сайте или очистив данные сайта в настройках браузера. Они не синхронизируются между устройствами. Не вводите конфиденциальные сведения о бизнесе, данные клиентов и сотрудников, пароли, платёжные реквизиты или государственные идентификаторы.

2. Агрегированная статистика использования

YOUNOVAL использует собственный счётчик на Supabase, чтобы понимать общую востребованность сайта и инструментов. Передаются только следующие события:

  • page_view — загрузка страницы;
  • tool_started — открытие одного из восьми инструментов;
  • tool_completed — получение результата инструмента.

В базе сохраняются дата по UTC, тип события, фиксированный идентификатор инструмента (для событий инструментов) и общий счётчик. Не сохраняются ответы, суммы, заметки, результаты, имена, адреса электронной почты, телефоны, идентификаторы посетителей, сессий или устройств. Эти счётчики не показывают число уникальных людей. Повторные и автоматизированные запросы также могут увеличить значения, поэтому статистика предназначена для ориентировочного анализа, а не для точного подсчёта аудитории.

3. Технические данные и сторонние сервисы

Публичная версия сайта размещается на Render. Для агрегированной статистики используются Supabase (проект расположен в регионе EU West, Ирландия) и его Edge Function. Шрифты загружаются через Google Fonts. Эти сервисы обрабатывают сетевые запросы и могут получать технические сведения, необходимые для доставки, защиты и работы сервисов, включая IP-адреса и технические журналы. Такие сведения не записываются в таблицу агрегированной статистики YOUNOVAL.

Точные сроки хранения технических журналов и полный состав технических данных зависят от настроек и правил соответствующих провайдеров. Перед окончательным юридическим утверждением уведомления оператору проекта необходимо проверить эти условия, расположение данных и применимые требования законодательства.

ENGLISH VERSION

How YOUNOVAL handles data

Last updated: 19 November 2026.

In short: no registration is required. Tool answers, entered figures, notes and results are processed in the visitor's browser and saved locally on that device. The site sends only fixed usage events and tool identifiers for aggregate statistics. Network requests may still involve technical data such as IP addresses.

1. Tool answers and results

YOUNOVAL tools calculate results in the browser. Answers, financial figures, notes and results are not sent to the application's database and are not visible to the project owner. The latest result for each tool and the selected language may be saved in browser localStorage so the visitor can return to them in the same browser on the same device. Results are not synced between devices.

Visitors can delete saved results using the “Clear results” control on the site or by clearing the site's browser data. Please do not enter confidential business information, customer or employee data, passwords, payment details or government identifiers.

2. Aggregate usage statistics

YOUNOVAL uses a counter hosted on Supabase to understand overall website and tool usage. It records page views, tool starts and tool completions. The database stores the UTC date, a fixed event type, a fixed tool identifier where relevant, and an aggregate count. It does not store answers, amounts, notes, results, names, email addresses, phone numbers, visitor IDs, session IDs or device identifiers. Counts are not unique visitors. Repeated or automated requests can also inflate them, so the statistics are intended for indicative analysis rather than exact audience measurement.

3. Technical data and third-party services

The public website is hosted on Render. Supabase (EU West, Ireland) and its Edge Function provide aggregate statistics. Fonts are loaded through Google Fonts. These providers may process technical connection information, including IP addresses and infrastructure logs, to deliver, secure and operate their services. Such information is not stored in YOUNOVAL's aggregate statistics table. Exact log retention and processing details depend on provider settings and policies and must be reviewed by the project operator.
